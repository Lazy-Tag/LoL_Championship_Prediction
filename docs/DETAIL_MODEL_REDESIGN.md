# 详细数据应怎样进入赛前预测

[诊断结果](../reports/detailed_data/diagnosis.md) · [数据覆盖](../reports/detailed_data/README.md) · [当前模型](../MODEL.md)

本文保留本轮运行前的实验设计。A1 训练端选边校正和 A2 经济残差已完成：[选边结果](../reports/detailed_data/joint_side_comparison.md)、[经济结果](../reports/detailed_data/economy_residual_comparison.md)。两者均不足以支持替换主结果；整届联合实力不确定性也已完成[独立回测](../reports/latent_events/README.md)；完整胜负／经济联合生成模型尚未实现。dynamic90 和 S16 预测保持不变。

## 重新界定问题

详细数据有三种用途：修正比赛条件、提供超出胜负的表现观测、说明一项估计有多可靠。应分别验证，不应把下载到的每一列都作为额外实力分数相加。

上一轮有两个结构性限制：红蓝方系数在原动态实力之外单独拟合，没有重估球队实力；经济项使用未校正对手的平均领先，随后直接修正胜率。这不是对“详细数据是否有用”的充分检验。

## 字段分工

| 数据 | 首选用途 | 不宜直接使用的方式 |
| --- | --- | --- |
| 小局胜负、对手、日期 | 动态实力的主观测；对账后的逐局重建 | 同时累计系列赛比分和同一批小局胜负 |
| 红蓝方 | 在历史胜负似然中校正比赛条件，与战队实力共同估计 | 保持原实力不变，只给预测概率加全局选边截距 |
| 10／15分钟经济差 | 衡量相对于对手、选边和已有实力预期的额外早期表现 | 将打弱队和打强队的相同经济领先视为同等证据 |
| 总经济、击杀、龙、塔、时长 | 数据核验；后续单独研究比赛过程或终局表现 | 用结算总经济替代缺失的15分钟经济，或把胜者天然占优的多项指标重复当作实力证据 |
| 阵容、选手与英雄 | 身份核验、阵容变更审计；保留供后续独立模型使用 | 当作赛前已知阵容；本轮重新开启已取消的全局 BP 模型 |
| 版本、赛事阶段 | 记录环境变化；有足够历史样本时做分层／收缩校正 | 为每个版本单独估计大量参数，或按整个赛季数据做标准化 |
| 缺失、来源、观测日期 | 控制哪些观测进入模型，以及估计的不确定性 | 把没有数据等同于经济持平、实力中等或必然较弱 |

已核对的年度候选记录中，S12–S15 的总经济、击杀、龙、塔字段全部非空，15分钟经济却存在大片缺失。覆盖广不是选取指标的充分理由；非空也不代表字段的含义跨版本一致。

## 第一步：让选边进入实力估计

对一局蓝方 i、红方 j 的比赛，候选模型为：

```text
P(蓝方胜 | 赛前状态) = logistic(θ_i(t) − θ_j(t) + b(t))
```

`θ` 保留当前赛区＋战队动态结构，`b` 是有收缩先验的蓝方关联效应。先用低维全局参数，样本足够后再单独验证赛事环境差异，避免直接按每个版本拆参数。`b` 不是蓝方的因果优势：选边权、队伍偏好等选择因素仍可能混杂。

关键是共同更新 `θ` 和 `b`。这样同样的一场胜利，模型会区分它发生在哪一侧。即使未来选边未知、最终预测仍需对两侧平均，历史校正后的战队实力也可能与原模型不同。上一轮仅在预测端平均正负截距，未检验这项收益。

对账成功的系列赛拆为有选边信息的小局，替换原比分的那部分似然；未对账的比赛继续保留胜负观测，不能只为获得完整选边而丢掉其他赛果。未知选边需要明确的边际化假设；它不等同于已知每局独立均匀选边。第一轮试验可沿用独立均匀近似，并明确报告覆盖分层结果。

验收包括：双方换位后概率互补；关闭选边项时恢复基线；所有原有小局胜负各贡献一次；同日顺序不影响结果。

## 第二步：先识别经济中的增量信号

以15分钟经济差为唯一首发经济指标，避免同时加入高度相关的10分钟经济、塔、龙、击杀。首先建立赛前条件下的经济预期：

```text
经济预期 μ_g = a × 赛前实力差 + 蓝方经济偏移 + 必要的环境项
经济残差 r_g = 实际15分钟经济差 − μ_g
```

上述形式是待检验的低维近似，不是假定真实关系必为线性。经济预期参数、尺度及误差分布只能用当前比赛日之前的当季数据估计；每条历史残差必须使用它自身开赛前的预测，不能用赛季末拟合模型回填。极端值可用稳健误差模型处理，不能按国际赛得分反复选择截断值。

“对手校正”体现在预期由双方赛前实力共同决定。表现好坏看的是超出预期多少。例如两场都领先2000经济，但赛前预期分别领先3000和落后1000，其残差分别为−1000和＋3000；这与原始领先均值是不同的信息。

随后用对局差分观测估计缓慢变化的队伍早期残差状态：

```text
r_g ≈ e_i(t) − e_j(t) + 观测噪声
```

不把两队各自的滑动平均当作独立观测。使用90天动态记忆与强收缩，保留状态方差；赛季初重置。经济关系图不连通时，不能从各国内联赛的残差推出新的跨赛区强度。跨赛区基准仍由原国际赛先验和国际赛胜负支撑；经济状态的跨池中心及预测修正必须明确约束，无法识别的比较保守关闭。

经济残差是相对于已有模型的意外表现，并非自动等于可持续实力。下一项实验首先验证它是否在后续日期仍有重复性，再验证是否能改进下一场胜负概率。没有后续预测价值时，不进入冠军模型。

## 第三步：将缺失建模为信息不足

每队至少记录：最后一次有效经济观测日期、累计观测数、90天衰减权重和、加权样本有效量、所属来源及覆盖情况、经济状态的后验方差。

注意两种量不同：`Σw` 随数据陈旧衰减，而 Kish 有效样本量 `(Σw)²/Σw²` 在所有旧权重同比衰减时不变。不能只靠后者判断数据是否新鲜；原先累计至少5局的门槛也不够。

- 某局经济缺失：保留该局胜负更新，不执行经济观测更新。
- 长期没有新经济：预测状态按90天记忆回归，状态不确定性按动态模型传播。不能一直沿用旧优势。
- 只有一方有可靠经济：首个保守方案关闭该对局的经济修正；更一般的方案对缺失方状态积分，而不是当作精确零。
- 整个联赛缺失：记录来源／联赛层面的覆盖限制，不利用“缺失”本身推断队伍实力。
- 不将总经济、国际赛之后的数据或另一个赛季的数据填入缺失的国内15分钟经济。

第一轮门控方案只用于控制误用；它不能解决完整子集中的模型失配，也不保证整体提升。

## 更完整的方向：带相关观测的动态实力模型

如果分开的选边校正和经济残差实验显示稳定信号，再研究联合状态模型：总实力与早期表现为相关但不相同的状态；历史胜负与经济共同提供信息，观测噪声决定各自贡献。

同一小局的胜负与经济共享当场发挥，不能未经检验直接假定给定实力后两者独立，否则可能重复放大证据。可引入共同的当场表现变量，或明确建立 `p(经济 | 状态) × p(胜负 | 经济, 状态)`，在赛前预测时对未来经济积分。缺少经济时也要边际化该观测，而不是减少这场胜负的价值。

这是后续研究方向，不应跳过识别性、时间验证和条件相关检查直接声称优于现有模型。当前队伍每季独立和样本规模限制，也不适合一开始就加入大量选手、英雄、版本交互。

## 小局到系列赛的接口

如果不同局有不同选边条件，先计算每局条件胜率，再按比赛胜场与选边状态递推；不再一律将平均胜率代入固定 BO 多项式。选边由此前输赢影响时，需要对应赛事规则或明确的策略情景，不能偷用真实未来选边。

若采用整个系列赛共享的未知状态，须先在每个状态下计算系列赛概率，再对状态平均。一般而言，`E[BO(p)]` 不等于 `BO(E[p])`。这一改动本身也是独立实验因素，不能和经济项同时修改后把全部收益归功于数据。

在尚未核准这些规则时，保持当前系列赛近似，并将“有条件的单局预测”和“赛前未知选边的系列赛预测”分开评价。

## 下一轮固定的对照顺序

| 顺序 | 改动 | 要回答的问题 |
| --- | --- | --- |
| A0 | 原 dynamic90 | 基准能否逐条复现？ |
| A1 | 仅在训练中联合估计选边与实力 | 详细选边能否提高历史实力估计质量？ |
| A2 | A1 加对手校正的经济残差状态，处理可靠性与缺失 | 经济是否提供超出胜负和选边的信息？ |
| A3（独立后续） | 概率计算中积分状态不确定性 | 改善来自概率校准还是经济信号？ |

新增核准赛果另做数据覆盖实验，不与上述算法改动混合。先比小局／系列赛对数损失、Brier、校准、命中率和各赛区覆盖，再考虑昂贵的整届冠军模拟。

所有状态、环境估计和校准系数在赛季内拟合；不以跨年训练替代当前赛季数据不足。开发阶段采用当季过去日期的滚动验证，固定处理方案后评价之后的比赛。S4–S15 国际赛已经多次查看，因此后续结果只能称为事后回测比较，不能重新包装成完全独立的留出验证；真正未查看的新赛事用于进一步确认。

主结果替换需要整体概率质量和分层稳定性支持，不能仅凭 S15 单年或冠军命中次数上涨。目前尚无这样的新证据，保持不覆盖。

## 相关研究及适用界限

[TrueSkill 2](https://www.microsoft.com/en-us/research/wp-content/uploads/2018/03/trueskill2.pdf)将额外比赛统计放进生成式实力估计，支持“改变从历史观测推断实力的方式”这一研究方向；其射击游戏结果不能直接外推至 LoL。

[Glicko-2](https://www.glicko.net/glicko/glicko2.pdf)明确区分评分、评分不确定性和波动性，可借鉴其区分估计值与可靠性的思想；本项目不因此改用其完整算法。

[PandaSkill](https://arxiv.org/abs/2501.10049)面向 LoL 研究选手表现与跨赛区评级，提示隔离赛区的评分可比性需要单独处理。当前按队伍建模、跨年隔离与不处理换人的边界不同，不能直接照搬。
