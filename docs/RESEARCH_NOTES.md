## 下载后首先检查什么

1. 先看实际最早、最晚日期和逐联赛计数，再相信文件名中的年份或“complete”。S6 的 complete 文件就没有覆盖全年全部赛事。
2. OE 通常每局有十个选手行和两个队伍行；统计小局时不能把十二行当作十二局。先验证蓝红两条队伍行，以及互补的 0／1 胜负。
3. 旧 Excel 的日期可能是序列数；列名可能用 `team`、`patchno`、`gdat15`，新 CSV 则用 `teamname`、`patch`、`golddiffat15`。统一字段映射，但保留原值。
4. 旧数值 game ID 可能只在平台内唯一；优先从来源链接保留平台及 ID。不要只按数值 ID 去重。
5. 队名别名限定在对应赛季。字符规范化不等于俱乐部身份核验，不能擅自把更名、分队或收购关系当作同一队。
6. 缺经济不填零。时长有分钟／秒差异；未核准单位时保留源值。逐分钟序列的第一个点不自动代表比赛第 1 分钟。
7. 元数据齐全不代表日期可靠；应将来源日期、标准化日期、日期偏移和处理原因分开保存。
8. 原始比分与详细小局先对账，再添加字段；同一系列赛不能既用比分累计胜负，又把小局作为额外胜负加入。

本轮新特征只接纳“同日、同一对队伍、全场小局比分一致、唯一匹配”的数据。跨日差异、未知别名、缺局和多组匹配均隔离。该策略保守，会漏掉真实可用数据；下一步应针对未匹配列表逐项核验，不能为了提高覆盖率放宽到无条件模糊匹配。

解析与字段覆盖见 [audit_detailed_data.py](../scripts/audit_detailed_data.py)，人工可读的 [异常清单](../reports/detailed_data/anomalies.md) 与 [对账结果](../reports/detailed_data/reconciliation.md) 分别回答“源记录是否合法”和“能否对应原有系列赛”，不是同一件事。

## 赛制如何记录与核验

逐届现有实现及近似见 [赛制说明](../reports/event_replay/rules.md)，参数见 [赛事配置](../data/event_replay/configs.json)。配置是本项目实现，不是官方规则原文；补查规则后应同时更新说明、配置和验证，不能只改介绍文字。

每届至少记录以下项目：

| 项目 | 必须区分的内容 |
| --- | --- |
| 阶段与参赛队 | 入围赛、正赛、轮空、直邀名额、晋级路径、赛前已经确定的种子 |
| 单场赛制 | 各轮 BO1／BO3／BO5；历史国内 BO2 不由最终 2:0 猜成 BO3 |
| 分组与循环 | 单／双循环、每组人数、晋级名额、同赛区回避、跨组安排 |
| 同分处理 | 相互战绩、净胜、加赛、时长等排序的优先级；缺失时明确近似 |
| 瑞士轮 | 战绩组、是否回避重赛、抽签顺延、豁免条件、晋级／淘汰场 BO |
| 淘汰赛 | 单败／双败、败者组去向、决赛是否重置、种子选对手与抽签限制 |
| 名次 | 共同淘汰阶段形成的名次区间，不能虚构精确低名次 |
| 实力更新 | 整届赛前冻结预测与逐日滚动预测分开，二者不能共用“准确率”标签 |

2020 MSC 应作为单独赛事配置，不能直接套 MSI 模板。历史 MSI 和 Worlds 均按具体年份配置，不用“都是 MSI”或“都是世界赛”代替核验。

### 已踩过的计算问题

- 瑞士轮不能只按当前胜负数合并状态：交手历史会改变下一轮合法配对。合法签表也不必等概率，须核对实际抽签过程。
- 33 场的 `2^33` 只是固定抽签策略下的胜负路径数量，不是含随机抽签的总情形数，也不是最优动态规划的复杂度下界。
- 固定淘汰树可以递推；四队双败入围赛可枚举；完整瑞士轮严格求和尚未实现。已有精确子程序不能推出全赛程精确。
- 14,000,605 次模拟只能减小抽样误差，不能修复错误规则、漏赛果或模型偏差。当前旧赛事的部分同分、抽签和选对手机制仍为近似。
- 每届种子使用公历年份；同年 MSI／MSC 和 Worlds 分别重新初始化随机数，不共享连续随机流。比较模型时保持同一赛制实现和模拟次数。
- 冠军命中、系列赛命中、排名相关和冠军概率的对数损失是不同指标；不能将其中一个改善描述为全部改善。

## 本次新特征实验的经验

[完整对比](../reports/detailed_data/model_comparison.md)覆盖 1,300 场历史国际赛系列赛。现有动态模型命中率 69.38%；增加历史15分钟经济后为 68.92%；再加入红蓝方为 68.85%，对数损失均变差。双方有足够历史经济的共同子集也没有改善，主结果保留 dynamic90。

这次是低维增量实验，不是全面否定经济数据。原始经济优势受对手实力、联赛风格和版本影响，不能直接解释为可跨赛区比较的实力。后续可以预先定义对手校正的经济模型，但不能不断按同一批国际赛效果调参后仍宣称独立验证。

- 只使用过去比赛的经济摘要；待预测比赛自己的15分钟经济属于未来信息。
- 所有当日比赛先预测再更新；不要依靠文件行顺序模拟开赛顺序。
- 阵容、实际选边和版本是否在赛前可知必须单独核实。本轮未知选边按两侧各50%假设边际化，没有使用实际未来选边。
- 新赛季队伍实力、经济状态和回归系数重置；仅上一季国际赛赛区先验可跨年。
- 新数据效果与新模型效果最好分开实验。本轮没有新增胜负样本，仅附加核准字段，避免将覆盖增加误当成模型改进。
- 同时报告全部样本和共同覆盖子集，避免详细数据只集中于特定联赛而产生选择偏差。

## 状态连锁的检验经验

[状态延续实验](../reports/form_chain/README.md)区分赛前预测和已知前几局后的实时预测。必须给基线同样的比分信息；领先本身提高赢系列赛概率，不是额外状态模型的贡献。实时局序只接受完整核验的局号和时间戳，不从最终比分猜第一局胜负。

本次近期超预期表现仍用90天，命中率略升而概率误差增大；系列赛共享状态在全部下一局样本上概率误差略降，但证据不稳定，首局后的第二局更差。已有动态模型本来就在更新近期实力，附加“连胜加分”必须证明增量价值。共享相关也可能来自实力估计误差、对位、选边和 BP，不能直接解释为士气或手感的因果作用。

## 系列赛状态与完整赛事模拟

[23届整届比较](../reports/form_chain/events/README.md)已完成。对于“实力冻结、每个系列赛状态独立、赛程只依赖系列赛胜者”的模型，可先对共享潜在单局胜率积分成 BO3／BO5 胜率，再复用完整赛制引擎；无需每次抽样都模拟每一小局。若加入跨系列赛状态继承、时长或地图净胜等影响，不能继续无条件使用这个简化。

本轮使用隔离扩展，不改原引擎与原结果的来源哈希。原输入和零相关输入均对23届逐一验证随机路径一致。新旧同种子有助于比较，但赛程路径分歧后随机调用序列也会改变，不应把全部完整路径当作严格一一配对。

实际结果是冠军概率对数损失与 Brier 略好，冠军命中不变，名次指标混合；不能仅看某项小幅上升就替换主模型。报告保留按赛事抽样的差异区间、逐届结果和所有队伍的实际／预测名次。

## 联合不确定性与整届状态的实现区别

两个候选应分开实验：一项抽取原模型联合后验，另一项固定均值后添加独立整届状态，避免把认知不确定性与真实状态波动重复计入。总实力协方差应由赛区＋战队状态映射为 HCHᵀ，不能只取每队方差而丢掉共同赛区及对局学习产生的相关项。

整届共享隐变量会使跨场结果相关，不能先将每场胜率分别平均再用固定概率表模拟。应每次完整模拟抽一次实力向量，并保持到赛事结束。对手选择策略也不能读取这个隐藏真值，否则相当于赋予参赛者额外信息。

为控制成本，可按本次抽样中的队伍对缓存 BO1／BO3／BO5 概率，不必每场重复计算，也不必在每次开局计算所有从未相遇的队伍对。零方差输入必须还原原引擎路径，联合采样的均值和正负协方差应单独验收。

两项独立实验现已完成，见[完整对比](../reports/latent_events/README.md)。直接积分现有高斯后验不一定改善预测：后验本身仍依赖先验、过程噪声和 Laplace 近似，不能把“考虑不确定性”自动等同于更准确。本次它只改善冠军 Brier，冠军对数损失、命中及名次变差。

固定0.35整届状态改善了平均冠军对数损失和 Brier，但名次变差；对数损失收益主要集中于2022 Worlds。应同时展示逐届影响和总体指标，不仅报告一个有利均值，也不能事后剔除冷门赛事来选择结论。是否采用必须结合新赛事验证，当前主模型保持不变。

## 本届赛事权重校准

对当前赛事的似然乘权重，应同时缩放梯度和 Hessian，不能只在输出胜率上加分；也不能修改原比分或再添加系列赛胜负。整数权重可用“仅在数值验证中复制该赛事的行”检查目标函数等价性，正式数据不复制。

本次固定网格 1／1.25／1.5／2／3／4，按更早年份的逐日外推结果选取；每届重置为原模型赛前状态，避免前一届放大权重污染本届基线。对 1,181 场非首日系列赛，原对数损失 0.57696；1.25 倍为 0.58170，2 倍为 0.59589。1.25 倍命中率虽略升，概率评分变差，不能据此认定改善。逐年保守选择均回到 1 倍，S16 当前赛中权重不变。

实现、逐场数据与验证见 `scripts/event_weighting.py`、`scripts/evaluate_event_weighting.py`、`scripts/verify_event_weighting.py` 和 [实验报告](../reports/event_weight/README.md)。没有重算冠军概率，主结果与既有每日快照不覆盖。

## 跨季阵容继承的时间隔离

本轮允许独立候选携带上一季战队偏移。阵容取已与比分唯一对账的小局；选手出场份额重合度作为人员折扣，不假定缺失名单全部留队。新季开季名单必须在当前国际赛之前已观察，之后才能条件化新季先验、重放此前赛果。不能拿赛季末阵容预测赛季初，也不能因为系列赛网页显示最终比分就提前使用。

同半衰期对照显示：跨季继承本身没有改善，稍长时间记忆带来小幅历史误差下降。必须保留“重置＋同半衰期”对照，不能把时间超参数的效果全部归因于人员建模。连乘表仅是先验状态转移系数，不等于经过非线性滤波后某场旧赛果的最终有效权重。方法见 [MODEL.md](../MODEL.md#跨赛季阵容继承实验)，[独立结果](../reports/roster_carry/README.md)未覆盖正式模型。
