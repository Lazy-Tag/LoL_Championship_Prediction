## 解释

对数损失越低越好，它同时惩罚过度自信的错误概率。逐场预测与冻结整届赛前实力的冠军预测不同。未考虑全局 BP、赛季中换人、替补、选边、版本效应与系列赛内相关性。历史训练数据仍有缺口，部分旧赛制的同分和抽签机制采用近似；这些误差不能通过增加模拟消除。
