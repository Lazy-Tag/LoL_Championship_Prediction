## 口径与局限

8月1日 GEN–DK 第一局的 GOL 队伍／选手关联和数值统计损坏；已用官方 game ID 对应的十人元数据恢复阵容、红蓝方、英雄、版本，并依据官方0:2确定该局胜者。原始错误记录保留，经济、KDA、补刀、伤害、视野与时长仍留空；不能把这一局当作完整数值样本。

人员、红蓝方、英雄和经济等来自 Games of Legends 的实际比赛页，胜负与原官方系列赛记录逐项核对；[官方赛程](https://lolesports.com/en-US/schedule)。源页面、来源链接及下载校验信息均保留。此补充只附加字段，不把同一小局作为新胜负重复加入训练，也未改动已发布预测。

“15分钟经济差”是相对对位／对手的差值，不是15分钟绝对经济；页面缺少的字段保留缺失，不填零、不由最终经济倒推。英雄使用来源图片资源标识，以避免部分页面 alt 引号损坏。小局真实时间戳、完整逐分钟经济曲线不在本轮已保证字段中。
