## 当前缺口

- S3 尚未取得可用的批量逐局详细文件；S4 有 78 局 WC 标签的逐分钟档案，缺精确日期。
- S5 目前仅有独立逐分钟档案；缺精确日期和版本，不能直接补进当前回测。
- S6–S9 本次 Excel 归档截止于各年 9 月，均不含 Worlds；S6 也缺 LPL 和 MSI。此前取得的独立 Worlds 镜像仍需与本批数据统一对账。
- S10–S15 年度文件已取得，但年度文件名不证明每个联赛或每个经济字段完整。
- S16 旧镜像全部层级截止于 2026-06-21，顶级／国际候选记录截止于 2026-06-14；7–10 月细节未补齐。
- 单局经济为空必须保留为空，不能填 0。时长单位保留源值，未跨版本强行统一。
