## 不确定性

按年份聚类计算；跨季状态仍会造成年份之间相关，因此这些区间仅供描述性参考。

- 阵容继承90天 相对原90天方案 的对数损失差：95% 年份聚类区间 [0.00000, 0.00028]；Brier 差 [0.00001, 0.00013]。负值较好。
- 按更早年份选择 相对原90天方案 的对数损失差：95% 年份聚类区间 [-0.00097, 0.00093]；Brier 差 [-0.00038, 0.00042]。负值较好。

## 解读范围

这里首次在独立候选中允许跨年战队实力输入；原模型依然每年重置。继承的是战队相对赛区的实力偏移，赛区先验仍按原 90 天方案从上一季国际赛估计。半衰期网格只改变战队偏移记忆，不改变赛区先验和随机游走尺度。

阵容仅来自与原比分严格对账的小局。上季取末次已知完整阵容，新季取首次已知完整阵容；替补按实际出场份额分配。上季阵容距离该队末场超过 45 天、新季首阵容距该队首场超过 30 天，或预测前尚未知晓，则不继承。只支持相同规范队名且原赛区一致的队伍；未核准的更名、收购和选手改名均可能造成低估。

用赛前已知的新季开季阵容重新条件化新季先验，再重放新季截至预测日之前的全部比赛；没有把较晚阵容用于预测更早比赛。阵容资格在每届赛事开赛时冻结，本轮未完整建模季中换人或人员位置效应。

S3–S5 缺可用于本模型的精确日期阵容；原始结果仍可形成赛区先验，但不能声称已按人员修正所有历史赛季。本轮 S16 开季诊断使用的既有详细镜像截止六月，不能视为世界赛当前阵容核验。本轮只评价逐场胜率，未重跑冠军与最终名次模拟。
