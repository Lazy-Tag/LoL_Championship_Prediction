# 共享临场状态：历史冠军与最终排名比较

[逐场状态实验](../README.md) · [各年赛制与近似](../../event_replay/rules.md)

S4–S15 共23届 MSI／MSC／Worlds。原模型是当前 dynamic90 主模型；候选加入每个系列赛独立的共享临场状态。赛前实力、训练截止、参赛队与赛制实现完全相同。每届每模型14,000,605次，种子为年份；原模型复用已校验的同规模模拟。主结果和 S16 概率未覆盖。

冠军对数损失为实际冠军概率的负对数；冠军 Brier 为当届全体战队概率误差平方和。预期名次相关使用 Spearman，绝对误差使用共同淘汰阶段区间中点；各届等权平均。相关系数不是百分比正确率。

## 差异是否稳定

以赛事为单位的配对 bootstrap（10,000次，种子2026），候选减原模型的平均指标差95%区间：

| 指标 | 区间 | 更好方向 |
| --- | --- | --- |
| 冠军对数损失 | [-0.04917, 0.02621] | 负 |
| 冠军 Brier | [-0.03159, 0.00497] | 负 |
| 预期名次相关 | [-0.00232, 0.00656] | 正 |
| 名次绝对误差 | [-0.00004, 0.02149] | 负 |

只有23届且此前已多次查看这些历史赛事；不同赛事也未必独立。区间是描述性参考，不是未见数据上的保证。新旧采用同年份种子，路径分歧后随机调用顺序可能变化，不能当作每条完整模拟路径始终一一配对。

## 每届独立赛制与计算方式

每届分别加载对应年份的参赛队、阶段、轮空、分组／瑞士轮、各轮 BO、单败／双败及晋级规则；2020 MSC 单列。没有用统一淘汰模板代替所有年份。旧同分、抽签和对手选择近似沿用基线，因此是相同规则情景下的模型对比，并非完全官方赛制复现。

系列赛潜在胜率 q 服从 Beta 分布，其均值为原单局胜率，相关强度ρ只用该赛事开赛前国内赛估计并冻结。先精确积分得到 BO3／BO5 胜率，再模拟整届；在仅依赖系列赛胜者、每场状态独立的假设下，与显式抽取 q 再逐局模拟的胜者分布等价。BO1 胜率不变。不同系列赛不继承刚才模拟的胜负，也不使用赛事中的真实比分更新。

因此本轮检验的是系列赛内共享状态对赛前冠军和名次分布的影响，不包含近期状态修正、跨场长期状态传播、参数不确定性、全局 BP、换人或选边。独立扩展引擎已验证：给原输入时，23届各1000次的全部名次计数及随机规则统计与原引擎一致。
