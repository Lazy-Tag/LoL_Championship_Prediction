## 阅读提示

概率为模拟估计。小于 0.01% 不代表不可能；相近概率的排名不应被解读为稳定差距。未考虑全局 BP、赛季中换人、替补、选边、版本效应与系列赛内相关性。历史训练数据仍有缺口，部分旧赛制的同分和抽签机制采用近似；这些误差不能通过增加模拟消除。
