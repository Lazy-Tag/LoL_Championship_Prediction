# 复算与数值验收

执行 `.venv/bin/python scripts/evaluate_event_targets.py`，再执行 `.venv/bin/python scripts/verify_event_targets.py`。输入为原 dynamic90 的23届赛前配置与已验证模拟计数。输出独立保存在 results/event_targets。

排名模型用 Plackett–Luce 无序淘汰组的精确集合概率，子集DP累加组内全部可能顺序，不使用两两排名伪似然，也不随意拆开并列。每届负对数似然除以队伍数减一，避免大赛事仅因队伍更多占据主导。预测名次边缘分布用指数竞赛表示和一维数值积分，浮点误差上界随结果保存；不是实际赛制路径的精确求和。

全部拟合只用更早年份；同年MSI不为Worlds提供结果标签。系数范围0.1至5，固定N(1,1)惩罚；先扫描41个点，再优化每个观察到的局部低谷并比较端点，减少单一起点的影响，不宣称数学上证明全局最优。少于4届时系数固定1。概率校准将零模拟概率以1e-12下限处理后归一化，仅用于该候选。

基线复用14,000,605次原模拟，不重新抽样。排名预测统一投影到各届共同淘汰阶段中点；等权组合混合整届排名分布，所以冠军和预期名次相容。只输出冠军的两个候选不编造名次或晋级路径。
