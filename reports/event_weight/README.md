# 本届赛事加权：赛中预测检验

只提高正在预测的这届赛事此前小局的影响，检验能否更快适应本届状态。首个比赛日没有本届历史，所有方案预测相同。

上表比较已有更早比赛日本届赛果的 1181 场系列赛；完整 1300 场评价另含各届首日。固定倍数是敏感性对照，“逐年选择”才是按此前年份选权重后的外推表现。

逐年选择相对原方案的对数损失差，按年份聚类的 95% bootstrap 区间为 [0.00000, 0.00000]；Brier 差区间为 [0.00000, 0.00000]。负值表示改善。仅有 12 个年份簇，区间应谨慎解读。若各年都选择 1 倍，差值区间为 [0,0] 仅表示两组预测完全相同，不代表已证明未来等效。

用 S4–S15 全部历史选择的 S16 候选权重为 **1 倍**。尚未达到预设推广条件，当前赛中主结果保持原权重，不因某个固定倍数在同一批数据上较好就替换。

## 范围与局限

覆盖 S4–S15 的 23 届 MSI／MSC／Worlds，训练仍包含当季此前全部已纳入比赛。每季重置战队实力，仅上一季国际赛提供赛区先验。同日所有预测在该日赛果进入前完成；权重只由更早年份选择，不能使用待预测年份成绩。

本届权重在赛事结束后丢弃，不带入另一届赛事。BO1／BO3／BO5 仍由小局胜率转换；没有再加入系列赛胜负，实际小局数和原比分不改变。

这次验证的是赛事进行期间的下一场胜率，未重跑整届冠军及最终名次回放，不能据此宣称冠军预测提升。历史覆盖缺口、未知阵容、全局 BP 和选边影响仍存在。加权属于有意调整学习强度，不能解释为获得了额外独立比赛证据。
