## 数据与限制

未考虑全局 BP、赛季中换人、替补、选边、版本效应与系列赛内相关性。历史训练数据仍有缺口，部分旧赛制的同分和抽签机制采用近似；这些误差不能通过增加模拟消除。

本次补充了阵容、版本、选边和局内统计的核验记录，尚未用于预测，也没有把缺失的比赛当作已经补齐。S3 因赛前数据不足不回放，仅保留[赛果](reports/history/S3/matches.md)。
